# Campus-Model
## Project Overview
A Campus Placement Preparation App is designed to help college students prepare for campus placements. Students can practice aptitude questions, improve coding skills, attend mock tests, learn interview techniques, and track their placement preparation progress through a single platform.

## Objectives
- Help students prepare for campus placement exams.
- Improve aptitude, reasoning, and coding skills.
- Provide mock tests and practice assessments.
- Support technical and HR interview preparation.
- Track student performance and learning progress.
  
## Features
- Student Login – Sign up and access a personal dashboard.
- Aptitude Practice – Quantitative aptitude and logical reasoning.
- Coding Practice – Programming questions and coding challenges.
- Mock Tests – Placement-style assessments with timers.
- Interview Preparation – Technical and HR interview questions.
- Placement Updates – Company details and eligibility criteria.
- Leaderboard – Compare scores with other students.
- Progress Tracker – View scores, strengths, and improvement areas.

## Design Highlights
- Modern blue, purple, and white colour theme.
- Clean dashboard with progress cards.
- Interactive quiz and coding screens.
- Clear progress bars and performance charts.
- Easy navigation with reusable Figma components.
